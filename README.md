# extension-sync-actions

基于 GitHub Actions 定期检查上游仓库的最新版本，自动完成代码拉取，打包并提交至 Chrome Web Store 进行审核发布。

## 📦 当前托管的扩展项目

本仓库目前同步以下两个扩展：

| 扩展名称 | 上游仓库 | 商店链接 |
| :--- | :--- | :--- |
| **Tree Style History - 树形历史** | [tumuyan/Tree-Style-History](https://github.com/tumuyan/Tree-Style-History) | [Chrome Web Store](https://chromewebstore.google.com/detail/khcenbpnhbeplojhaolbpldmoppicold) |
| **TabulaBili (初见哔哩)** | [wangdaodaodao/TabulaBili](https://github.com/wangdaodaodao/TabulaBili) | [Chrome Web Store](https://chromewebstore.google.com/detail/hjknablinpkpajdhjboogodgkpggffog) |

> ⚠️ **声明**：Tree Style History已获得原作者的授权，TabulaBili原作者并未限制他人上架，只需保留信息。
